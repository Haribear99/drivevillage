# DRIVE VILLAGE

**내 차의 실제 주행거리와 정비 주기로 자라고, 지난번 이후의 여정이 주차(P단)하는 순간 한 장면으로 정산되는 차량 전용 코지 마을.**

Pleos Connect(Android Automotive OS)용 **정차 중 전용** 앱이다. 주행 중에는 화면·소리·알림이 모두 0이다(fail-closed).
2026 현대자동차그룹 차량용 앱 개발 공모전 1차 제출용 MVP(0.1.1). 마을·주민·아트·대사는 모두 팀 오리지널이다.

## 실행 방법

| flavor | 용도 |
|---|---|
| `pleos` | 실제 차량 신호(AAOS `GEAR_SELECTION`·CarUxRestrictions + Pleos Vehicle SDK 2.3.2 Odometer). **제출·시연용.** 시험 입력·배속·더미 데이터 없음 |
| `demo` | 차량 없이 화면을 보기 위한 빌드. 화면 왼쪽 아래에 늘 **「시뮬레이션」** 패널(기어 P/D, 주행거리 +1/+10km, 날짜 +30일)이 보인다. 가짜 신호 코드는 `app/src/demo`에만 있다 |

```bash
./gradlew assemblePleosRelease      # 제출 APK
./gradlew assembleDemoDebug         # 시뮬레이션 APK
./gradlew testPleosDebugUnitTest    # JVM 단위 테스트
```

- JDK 17 이상, Android SDK 35. `local.properties`에 `sdk.dir` 지정.
- release 서명은 저장소 밖 키를 가리키는 `keystore.properties`(storeFile, storePassword, keyAlias, keyPassword, **커밋 금지·gitignore**)에서 읽는다. 없으면 서명되지 않은 release가 만들어진다.
- Windows에서 경로에 한글이 있으면 단위 테스트가 `ClassNotFoundException`으로 실패한다. `subst X: "<drivevillage 경로>"`로 ASCII 드라이브에 매핑한 뒤 그 드라이브에서 실행한다.

### 시연 순서(PT 스크립트 1~5·7단계 대응)

1. **기어 D** → 앱 화면이 즉시 닫히고 소리가 멈춘다. 다시 P가 돼도 저절로 뜨지 않는다(자동 실행·헤드업 팝업 금지 규정). 사용자가 앱을 다시 연다.
2. **주행거리 +N km → 기어 P → 앱 열기** → 「지난번 이후의 여정」 정산 카드(경과일·달린 거리·누적 거리·이정표) + 주민 한 문장(TTS 1회). 받은 것(재료·기념물·계절 장식)에 날짜·기억 태그가 붙는다.
3. **정비 공방**: 처음 열면 마지막 정비 시점(주행거리·날짜)과 차종 프리셋(가정값, 수정 가능)을 넣는다. 주행거리를 기준값 위로 넘기면(또는 날짜가 지나면) 부탁이 열리고, [했어요]·[예약했어요]·[다음에] 중 하나로 답한다. [했어요]는 공방을 증축한다.
4. **미션 탭**: 오늘의 미션 1개(기어·주행거리로만 판정), 도장 수집.
5. **꾸미기 탭**: 재료·기념물·장식 하나를 고르고 마을의 빈 자리(점선 원)를 누른다. 놓인 것을 누르면 그날의 기억 태그가 보인다.
7. **오프라인**: 대사는 처음부터 템플릿 렌더러라 네트워크 없이 같은 흐름으로 동작한다.

## 테스트 환경

- JVM 단위 테스트: Windows 11, JDK 20, Gradle wrapper(AGP 8.8.2, Kotlin 2.0.0).
- 에뮬레이터: Android Automotive 33 AVD(`aaos33`, 1024×768). `adb shell cmd car_service inject-vhal-event 0x11400400 4|8`로 기어 P/D 주입.
- 실제 Pleos 차량·Pleos 전용 AVD에서는 시험하지 못했다(아래 '검증 상태').

## MVP 범위

| 기능 | 규칙 |
|---|---|
| 주행 중 0 | 기어 P **AND** UX 제한 없음일 때만 마을 화면. 비P·제한·확인 불가·값 상실이면 즉시 종료하고 소리를 끊는다(되돌릴 수 없는 세션 래치, 3초 안에 판정 못 하면 종료) |
| 여정 정산(지난번 이후의 여정) | 마지막 정산 대비 주행거리 증가 ≥ 1km일 때. 카드에 직전 정산 이후 경과일·달린 거리·누적 거리·넘은 이정표를 한꺼번에 보인다. 기준값·장면 기록·재료·미션 도장을 한 파일에 원자 저장 → 같은 증가분으로 두 번 지급하지 않음(재시작 포함). 1km 미만은 다음 정산에 합산, 읽기 실패·0km는 보류, 값 역전은 다음 정산에서 한 번 더 확인된 뒤에만 기준값 재설정, 판독 중 화면이 닫히면 저장하지 않음 |
| 성장 입력 | **정산 재료**: 정산 1회 = 1개, 하루 상한 1회. **이정표 기념물**: 정산 누적 거리 1,000km마다 1개. 한 번에 여러 개를 넘어도 **정산 1회 최대 3개**(과주행 유도 방지 상한). 상한에 걸린 기념물은 사라지지 않고 다음 정산으로 넘어가며, 같은 이정표로 두 번 주지 않음. **계절 장식**: 새 계절(봄 3~5월·여름 6~8월·가을 9~11월·겨울 12~2월) 첫 정산에 1개. **정비 응답**: 공방 톱니 1개(퀘스트 주기마다 1회). **정비 기념패**: '했어요'에 정비 당시 주행거리를 넣으면 1개(주행거리를 읽었을 때만, 0~현재 값). 입력값은 기념패에 기록만 하고 기준점에는 쓰지 않는다. 모든 아이템에 날짜·한 줄 기억 태그(프리셋 5종)·출처 이벤트 id. 기기 날짜가 시계 하한(2026-11-01)보다 이르면 정산 보류, 시계가 하루 뒤로 가도 이중 지급 없음 |
| 마을 레벨 | 성장 입력의 누적 점수: 재료·톱니 1점, 계절 장식·기념패 2점, 이정표 기념물 3점, 5점마다 1레벨(팀 가정값) |
| 소리 | 탑승(움직임 없음) 1문장, 하차(장면) 1문장, 각 1회만(같은 저장에 기록). 소리 끔 토글. 주민이 먼저 말을 거는 경로 없음 |
| 정비 공방 | 엔진오일·필터, 냉각수 **수위 점검**(월 1회 체크인), 타이어 공기압(월 1회), 타이어 위치 교환, 공조 필터, 등화 점검. km·날짜 중 먼저 도래하는 쪽으로 열림. 응답은 **했어요 / 예약했어요 / 다음에** 3개이고 무엇을 눌러도 같은 작은 보상(공방 톱니), 같은 퀘스트 주기 안에서는 1회. **했어요**: 기준점을 지금(주행거리·날짜)으로 갱신하고 공방 1단계 증축, 정비 당시 주행거리를 넣으면(선택) 기념패 1개 추가(입력값은 기념패에만 기록). **예약했어요**: 14일 뒤 재확인. **다음에**: 500km 또는 14일 중 먼저 오는 쪽에 재알림(팀 가정값, `Maintenance` 상수). 응답은 사용자의 자기 신고이며 앱은 정비 여부를 알 수 없다. 사진 증빙은 폰 2단계 |
| 프리셋(가정값) | 쏘나타 DN8 HEV 통상 15,000km/12개월·가혹 7,500km/6개월(같은 그룹 참고치), 그랜저 GN7 HEV 가혹 5,000km/6개월, 투싼 NX4 가솔린 10,000km/12개월, 직접 입력. 모두 사용자가 고칠 수 있다 |
| 미션(조연) | 「주행 후 P단으로 정차하기」(기어), 「짧은 이동도 기록하기」(주행거리 5km 미만). 날짜로 하루 1개, 도장 최대 1개. 페널티·점수·연속일수·과속 미션 없음 |
| 마을 뷰어 | Canvas 도형으로 그린 공방(단계별 증축)·우물·정원·가로등(저녁·밤 점등)과 주민 3명: 공방 장인 **도담**, 여행가 **나들**, 정원사 **소이**. 슬롯 8곳에 아이템 1개씩 놓기 |
| 주민 대사 | `TripSummary`(주행거리 증가, 시간대, 마을 경과일, 열린 퀘스트, 오늘 놓은 재료)를 슬롯으로 채우는 **템플릿 렌더러**. 사실·수치는 코드가 채우고 문장 변주만 템플릿 풀에서 고른다. 렌더 결과는 검증기(남은 슬롯·입력에 없는 수치·금칙어 0)를 통과해야 하며 실패하면 안전 문장으로 대체 |
| 권한 | `android.car.permission.CAR_POWERTRAIN`(기어), `pleos.car.permission.CAR_DRIVE`(주행거리). 둘 다 normal. 차량 제어(쓰기) 없음 |

## 오늘 결정 반영(2026-11-15, v0.1.1)

1. **재진입 → 여정 정산 리듬**: '오늘의 장면'을 '지난번 이후의 여정'으로 바꿨다. 정산 카드에 직전 정산 이후 경과일·달린 거리·누적 거리·이정표를 함께 보인다. 앱을 안 연 날이 있어도 달린 거리·이정표 기념물(상한에 걸리면 다음 정산으로 넘어감)·정비 부탁은 사라지지 않고 다음 정산에 합쳐진다는 문구를 넣었다. 단, 정산 재료는 정산 1회당 1개(하루 상한 1회)라 자주 열수록 재료는 더 받는다. 그래서 카드에 "재료만은 정산할 때 하루 하나"라고 함께 적었고, '모든 보상에 손해가 없다'고는 쓰지 않았다.
2. **성장 = 다양성 기반**: '하루 1회 2개, 거리 무관' 지급을 없앴다. 성장 입력은 정산 재료(하루 1회), 1,000km 이정표 기념물(정산 1회 최대 3개), 정비 응답 보상, 새 계절 첫 정산의 계절 장식이고, 마을 레벨은 이들의 누적 점수로 정한다.
3. **정비 = 응답만 보상 + 선택 증빙**: 했어요 / 예약했어요 / 다음에 3개 응답, 같은 보상을 주기마다 1회. '했어요'에 정비 당시 주행거리를 넣으면 기념 장식 1개를 더 준다. 사진 증빙은 넣지 않았다(폰 2단계).
4. 0.1.0 저장 파일(하루 재료 2개)도 손상으로 보지 않고 그대로 이어서 정산한다. 0.1.0 때 누적 거리가 이미 1,000km를 넘었다면 0.1.1 정산부터 그 이정표 기념물을 정산마다 최대 3개씩 지급한다.

## 검증 상태(정직하게)

- JVM 단위 테스트(0.1.1): **93개, 실패 0**. 0.1.1에서 정산 재료 하루 1회, 이정표 1,000km·정산 1회 최대 3개·이월·중복 없음, 계절 장식 1회, 마을 레벨 누적, 정비 응답 3종의 같은 보상·주기당 1회, 했어요 기준점 갱신·기념패, 예약 14일 재확인, 다음에 500km/14일, 보상 반복 획득 경로 차단, 0.1.0 저장 파일 이어서 정산을 추가했다. 0.1.0까지의 항목(시계 역행·앞섬, 주행거리 일시 오류값·실제 역전 포함. 래치 9조합·중간 D 신호, 정산 멱등성·재시작 반복 추가 지급 0, 재료 하루 1회·거리 무관 동일량, 퀘스트 km 선도래·날짜 선도래·둘 다·주행거리 불명, 냉각수 월 1회, 완료 신고 1회, 미션 하루 1도장, 꾸미기 규칙, 한 문장 1회, 템플릿 슬롯 위반 0, 저장소 손상 거부·직렬화).
- 적대적 코드 리뷰(별도 에이전트) 5라운드: r1 치명 1·중대 5 → r2 중대 2 → r3 중대 1 → r4 중대 1 → **r5 치명·중대 0**. 매 라운드 지적을 반영하고 회귀 테스트를 추가했다.
- 0.1.1 적대적 코드 리뷰 3라운드: r1 중대 2·조건부 중대 1(오래된 정비 km로 보상 반복, 기념물 상한 초과분 소실과 '손해 없음' 문구, 앞선 시계로 저장된 퀘스트 날짜) → r2 중대 1(하한값 입력 + 짧은 주행 반복) → **r3 치명·중대 0**.
- 0.1.1 pleos release: VHAL P 주입 후 열기 → 마을 화면, 열린 채 D 주입 → `stop latch`·`screen=CLOSE latch=gear-NOT_PARK`(주입 명령 직전 시각부터 약 0.16초, 1회). demo 빌드에서 0.1.0 저장 파일을 그대로 읽어 정산 카드(경과 30일·10km·재료+계절 장식), 정비 응답(다음에·했어요+기념패), 마을 레벨 표시를 화면으로 확인(정비 기준점 수정 전 빌드).
- aaos33 에뮬레이터, pleos release(최종 빌드): VHAL로 P 주입 후 열기 → 마을 화면, 열린 채 D 주입 → 화면 종료·소리 정지 호출 3/3(주입 명령 직전 시각부터 래치 로그까지 약 0.1~0.2초, adb 왕복 포함). D 상태에서 열면 즉시 종료(`latch=ux-restricted`). 이 AVD에는 Pleos 차량 서비스 권한이 없어 Odometer 호출이 `SecurityException`으로 실패 → 장면은 '보류'로 안전하게 처리된다. **그래서 pleos 빌드로는 장면·TTS 흐름을 에뮬레이터에서 보지 못했다.**
- demo debug 빌드(시뮬레이션): 장면 TTS 재생 중 기어 D → `STOPPED`(재생 루프 중단) 3/3, 래치 정지 호출 뒤 약 80~100ms(로그 근거, 귀로 들은 확인 아님, 리뷰 반영 전 빌드에서 측정·음성 코드는 이후 변경 없음). 첫 실행·탑승 인사, +10km 후 장면·재료·TTS, 정비 설정 저장 → km 선도래 퀘스트 열림 → 완료 신고 → 공방 증축, 날짜 +30일 → 냉각수·공기압 체크인 열림, 재료 놓기·기억 태그 표시를 화면으로 확인.
- **미검증**: 실제 Pleos Vehicle Service 연동(권한 부여·Odometer 값 단위·콜백), 실차 UX 제한 동작, 실제 스피커 출력(로그 근거만, 귀로 들은 확인 아님).
- 서명 인증서는 이전 출품작과 같은 팀 키를 재사용해 인증서 DN에 이전 앱 이름이 남아 있다(앱 이름·패키지와는 무관).
- 남은 위험(수용): Pleos Odometer 값의 단위·누적 여부 미검증(m 단위라면 장면이 과하게 생김), 가까운 오류값이 두 번 연속 읽히면 역전으로 확정될 수 있음, 저장 형식 version 마이그레이션 없음, 시계가 이틀 이상 뒤로 가면 정비 응답 보상을 1회 더 받을 수 있음, 주행거리를 모른 채 '했어요'를 기록하면 그 주기는 날짜로만 다시 열림.
- 시계 하한(`SceneLedger.CLOCK_FLOOR_EPOCH_DAY`)은 릴리스할 때마다 그 빌드 날짜 무렵으로 올린다.
