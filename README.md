# DRIVE VILLAGE

**내 차의 실제 주행거리와 정비 주기로 자라고, 그날의 여정이 주차(P단)하는 순간 한 장면으로 남는 차량 전용 코지 마을.**

Pleos Connect(Android Automotive OS)용 **정차 중 전용** 앱이다. 주행 중에는 화면·소리·알림이 모두 0이다(fail-closed).
2026 현대자동차그룹 차량용 앱 개발 공모전 1차 제출용 MVP(0.1.0). 마을·주민·아트·대사는 모두 팀 오리지널이다.

## 실행 방법

| flavor | 용도 |
|---|---|
| `pleos` | 실제 차량 신호(AAOS `GEAR_SELECTION`·CarUxRestrictions + Pleos Vehicle SDK 2.3.2 Odometer). **제출·시연용.** 시험 입력·배속·더미 데이터 없음 |
| `demo` | 차량 없이 화면을 보기 위한 빌드. 화면 왼쪽 아래에 늘 **「시뮬레이션」** 패널(기어 P/D, 주행거리 +1/+10km, 날짜 +30일)이 보인다. 가짜 신호 코드는 `app/src/demo`에만 있다 |

```bash
./gradlew assemblePleosRelease      # 제출 APK
./gradlew assembleDemoDebug         # 시뮬레이션 APK
./gradlew testPleosDebugUnitTest    # JVM 단위 테스트
```

- JDK 17 이상, Android SDK 35. `local.properties`에 `sdk.dir` 지정.
- release 서명은 저장소 밖 키를 가리키는 `keystore.properties`(storeFile, storePassword, keyAlias, keyPassword, **커밋 금지·gitignore**)에서 읽는다. 없으면 서명되지 않은 release가 만들어진다.
- Windows에서 경로에 한글이 있으면 단위 테스트가 `ClassNotFoundException`으로 실패한다. `subst X: "<drivevillage 경로>"`로 ASCII 드라이브에 매핑한 뒤 그 드라이브에서 실행한다.

### 시연 순서(PT 스크립트 1~5·7단계 대응)

1. **기어 D** → 앱 화면이 즉시 닫히고 소리가 멈춘다. 다시 P가 돼도 저절로 뜨지 않는다(자동 실행·헤드업 팝업 금지 규정). 사용자가 앱을 다시 연다.
2. **주행거리 +N km → 기어 P → 앱 열기** → 오늘의 장면 카드 + 주민 한 문장(TTS 1회). 재료 2개(하루 1회, 거리와 무관)에 날짜·기억 태그가 붙는다.
3. **정비 공방**: 처음 열면 마지막 정비 시점(주행거리·날짜)과 차종 프리셋(가정값, 수정 가능)을 넣는다. 주행거리를 기준값 위로 넘기면(또는 날짜가 지나면) 부탁이 열리고, [완료 신고]를 누르면 공방이 증축된다.
4. **미션 탭**: 오늘의 미션 1개(기어·주행거리로만 판정), 도장 수집.
5. **꾸미기 탭**: 재료 하나를 고르고 마을의 빈 자리(점선 원)를 누른다. 놓인 재료를 누르면 그날의 기억 태그가 보인다.
7. **오프라인**: 대사는 처음부터 템플릿 렌더러라 네트워크 없이 같은 흐름으로 동작한다.

## 테스트 환경

- JVM 단위 테스트: Windows 11, JDK 20, Gradle wrapper(AGP 8.8.2, Kotlin 2.0.0).
- 에뮬레이터: Android Automotive 33 AVD(`aaos33`, 1024×768). `adb shell cmd car_service inject-vhal-event 0x11400400 4|8`로 기어 P/D 주입.
- 실제 Pleos 차량·Pleos 전용 AVD에서는 시험하지 못했다(아래 '검증 상태').

## APK 위치

- 제출 APK: 프로젝트 상위 폴더 `docs/deliverables/drivevillage-0.1.0-pleos-release.apk`(release, 서명됨). 빌드 산출물 원본은 `app/build/outputs/apk/pleos/release/app-pleos-release.apk`.

## MVP 범위

| 기능 | 규칙 |
|---|---|
| 주행 중 0 | 기어 P **AND** UX 제한 없음일 때만 마을 화면. 비P·제한·확인 불가·값 상실이면 즉시 종료하고 소리를 끊는다(되돌릴 수 없는 세션 래치, 3초 안에 판정 못 하면 종료) |
| 오늘의 장면 | 마지막 정산 대비 주행거리 증가 ≥ 1km일 때. 기준값·장면 기록·재료·미션 도장을 한 파일에 원자 저장 → 같은 증가분으로 두 번 지급하지 않음(재시작 포함). 1km 미만은 다음 정산에 합산, 읽기 실패는 보류, 값 역전은 기준값만 재설정 |
| 재료 | 하루 1회 2개(거리와 무관). 재료마다 날짜·한 줄 기억 태그(프리셋 5종 중 선택)·출처 장면 id |
| 소리 | 탑승(움직임 없음) 1문장, 하차(장면) 1문장, 각 1회만(같은 저장에 기록). 소리 끔 토글. 주민이 먼저 말을 거는 경로 없음 |
| 정비 공방 | 엔진오일·필터, 냉각수 **수위 점검**(월 1회 체크인), 타이어 공기압(월 1회), 타이어 위치 교환, 공조 필터, 등화 점검. km·날짜 중 먼저 도래하는 쪽으로 열림. 완료는 **자기 신고**(차량은 정비 여부를 알 수 없음), 신고마다 공방 1단계 증축. 같은 주기 재신고 불가 |
| 프리셋(가정값) | 쏘나타 DN8 HEV 통상 15,000km/12개월·가혹 7,500km/6개월(같은 그룹 참고치), 그랜저 GN7 HEV 가혹 5,000km/6개월, 투싼 NX4 가솔린 10,000km/12개월, 직접 입력. 모두 사용자가 고칠 수 있다 |
| 미션(조연) | 「주행 후 P단으로 정차하기」(기어), 「짧은 이동도 기록하기」(주행거리 5km 미만). 날짜로 하루 1개, 도장 최대 1개. 페널티·점수·연속일수·과속 미션 없음 |
| 마을 뷰어 | Canvas 도형으로 그린 공방(단계별 증축)·우물·정원·가로등(저녁·밤 점등)과 주민 3명: 공방 장인 **도담**, 여행가 **나들**, 정원사 **소이**. 슬롯 6곳에 재료 1개씩 놓기 |
| 주민 대사 | `TripSummary`(주행거리 증가, 시간대, 마을 경과일, 열린 퀘스트, 오늘 놓은 재료)를 슬롯으로 채우는 **템플릿 렌더러**. 사실·수치는 코드가 채우고 문장 변주만 템플릿 풀에서 고른다. 렌더 결과는 검증기(남은 슬롯·입력에 없는 수치·금칙어 0)를 통과해야 하며 실패하면 안전 문장으로 대체 |
| 권한 | `android.car.permission.CAR_POWERTRAIN`(기어), `pleos.car.permission.CAR_DRIVE`(주행거리). 둘 다 normal. 차량 제어(쓰기) 없음 |

## 미구현(2차 PT 범위 이후)

- **LLM 연동**: `LineGenerator` 인터페이스만 있다(`core/village/Dialogue.kt`). 2차 PT 범위이며, 연동 뒤에도 같은 `TripSummary`만 입력으로 받고 검증기·템플릿 폴백을 유지한다.
- **장소(TourAPI)**: 이번 MVP에는 없다. 더미 장소 데이터도 넣지 않았다. 2차 범위.
- 휴대폰 동반 앱, 주민 관계 단계·입주 조건, 선택지형 대화·STT, EV 충전 모드, 동승 대사 변주, 냉각수 교체(희귀 이벤트)·브레이크액 퀘스트, 마이현대 딥링크, 과속 미션(조건부 로드맵), Gleo 연동.

## 검증 상태(정직하게)

- JVM 단위 테스트: **73개, 실패 0**(래치 9조합·중간 D 신호, 정산 멱등성·재시작 반복 추가 지급 0, 재료 하루 1회·거리 무관 동일량, 퀘스트 km 선도래·날짜 선도래·둘 다·주행거리 불명, 냉각수 월 1회, 완료 신고 1회, 미션 하루 1도장, 꾸미기 규칙, 한 문장 1회, 템플릿 슬롯 위반 0, 저장소 손상 거부·직렬화).
- aaos33 에뮬레이터, pleos release: VHAL로 P 주입 후 열기 → 마을 화면, 열린 채 D 주입 → 화면 종료·소리 정지 호출 3/3(로그 간격 약 0.14~0.2초, adb 왕복 포함). 이 AVD에는 Pleos 차량 서비스 권한이 없어 Odometer 호출이 `SecurityException`으로 실패 → 장면은 '보류'로 안전하게 처리된다. **그래서 pleos 빌드로는 장면·TTS 흐름을 에뮬레이터에서 보지 못했다.**
- demo debug 빌드(시뮬레이션): 첫 실행·탑승 인사, +10km 후 장면·재료·TTS, 정비 설정 저장 → km 선도래 퀘스트 열림 → 완료 신고 → 공방 증축, 날짜 +30일 → 냉각수·공기압 체크인 열림, 재료 놓기·기억 태그 표시를 화면으로 확인.
- **미검증**: 실제 Pleos Vehicle Service 연동(권한 부여·Odometer 값 단위·콜백), 실차 UX 제한 동작, 실제 스피커 출력(로그 근거만, 귀로 들은 확인 아님).
- 서명 인증서는 이전 출품작과 같은 팀 키를 재사용해 인증서 DN에 이전 앱 이름이 남아 있다(앱 이름·패키지와는 무관).

## 구조

```
core/gate      표시 판정(fail-closed)과 세션 상태기계, 안전 래치      ← 순수 Kotlin, 단위 테스트
core/village   장면 정산·재료·미션·꾸미기(SceneLedger), 정비 퀘스트(Maintenance),
               주민·대사 템플릿 렌더러와 검증기(Dialogue)              ← 순수 Kotlin, 단위 테스트
core/voice     목소리 허용 판정·재생 중단 규칙·WAV 읽기               ← 순수 Kotlin, 단위 테스트
data           원자적 파일 저장, 상태 검증기, 직렬화 저장소
vehicle        AAOS 기어(GEAR_SELECTION)·CarUxRestrictions 감시, Pleos Odometer 래퍼(실패는 UNKNOWN/보류로)
ui             Compose 화면, Canvas로 그린 오리지널 마을·주민, 정차 중 한 문장 TTS
```
